## 페이지

- [[architecture]] — 구조와 파이프라인: 사진 → OCR(단어·좌표·방향) → 1단계 LLM(이름·가격·좌표, 병렬 묶음) → 2단계 LLM(설명, 캐시) → 화면. 파일 지도, NDJSON 이벤트, 검증 절차(헤드리스 Chrome 흐름)
- [[benchmarks]] — 처리 시간 측정 기록: Document Parse vs OCR, 모델 3종 비교, 2단 분리 전후, 안내문 문단 덮개, 자동 제목 필드 전후. 재현 명령
- [[overlay-and-photo]] — 화면 좌표 규칙: OCR 단어 상자 합집합, EXIF·글자 방향·기울기 보정, 글자 영역 확대, 칩/배지 선택 규칙, 안내문 문단 덮개·번호 판정(coverLayout)과 정리 영역(요약·번역문·원문), 핀치 줌과 스크롤
- [[deploy-and-env]] — Vercel(Node 런타임, 도쿄, Git 자동 배포), 환경변수(+자동 주입 `VERCEL`), Redis Cloud 연결 경위와 키·용량(가득 차면 쓰기 실패), 초대 코드 게이트, 비용
- [[debug-store]] — 진단 저장: 켜는 법, 내려받기, 사용자 실기기 케이스 재현 절차, 끄는 시점, 용량 관리(오래된 것부터 삭제)
- [[icons]] — 보유 도트 아이콘 목록(자동 생성)·매칭 순서·런타임 생성 파이프라인. 제작 규칙은 `.claude/skills/pixel-icon`
- [[design-decisions]] — 결정 허브: 작업 원칙(빨리 보여줄 수 있는 것은 빨리), 공통 결정(시안 A, 언어 규칙, 아이콘 선택·생성, 가격 표기), 폐기·보류. 화면별 결정은 아래 세 장
  - [[decisions-result]] — 결과 화면: 오버레이 기본·표시 방식·배지, 대표 이미지, 상세 시트, 카드 묶음·배지, 주문서·주문 문구, 챗(시트·키보드), 사진 저장
  - [[decisions-talk]] — 대화 통역: 홈 탭, 말풍선 세 줄, 크게 보여주기, 표시 언어, 도우미, 말하기·글로 쓰기, 음성 인식 불가 안내, 대화 기록, 서비스 선택
  - [[decisions-input]] — 입력·처리·기록: 홈 문구·입력 3경로, 모음 화면·여러 장·촬영·자르기, iOS 홈 앱, 처리 중 화면, 중단 확인, 기록 보관·목록 개편(썸네일·자동 제목·이름 고치기)·지우기 확인
