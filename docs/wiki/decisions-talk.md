# 대화 통역 결정 (확정)

> [[design-decisions]] 의 하위 페이지. 홈 「대화 통역」 탭, 대화 화면(말하기·글로 쓰기·크게 보여주기·표시 언어·도우미), 대화 기록에 관한 확정 결정. 바뀌면 이 페이지와 로그를 같이 갱신한다. 서버 흐름은 [[architecture]], 키·비용은 [[deploy-and-env]], 측정은 [[benchmarks]].

## 기획 (2026-10-23 사용자 시안 피드백)

- 시안 3안(마주 보기·대화 + 크게 보여주기·자동 자막) 중 **「대화 + 크게 보여주기」 한 안으로 확정**. 마주 보기(위아래 분할)는 「마이크가 거기 없어서」 폐기. 상황(라멘집·약국 등)을 먼저 고르는 방식도 폐기: 새 대화를 시작하면 그걸로 진행하고, 목록은 나중에 기록에서 본다. 음성 출력(TTS)은 필요 없음.
- **같은 계층**: 홈 맨 위 탭 「사진 읽기 | 대화 통역」(마지막 고른 탭 기억, 글자 앞 도트 글리프는 [[decisions-input]] 홈 탭). 헤더 배지는 탭에 따라 「日本語 → 한국어」/「한국어 ⇄ 日本語」. 전체 기록도 「사진 | 대화」 탭.

## 대화 화면

- **말풍선 세 줄만**: 위 작은 줄(내가 한 원문, 음성 인식 오류를 고친 것), 가운데 큰 줄(상대가 읽을 언어), 아래 발음(일본어일 때, 주홍). 되돌려 확인·버튼류는 넣지 않는다(시안 B 「지저분하다」 피드백). 내 말은 오른쪽 종이색(도트 그림자), 상대 말은 왼쪽 먹색. 한 턴씩 주고받지 않아도 되고, 같은 사람이 이어 말하면 간격을 좁혀 붙인다.
- **크게 보여주기**: 내 말풍선을 누르면 화면 가득 일본어 + 히라가나, 아래 「내가 읽을 발음」. 첫 내 말풍선이 생기면 목록 위에 안내 한 줄.
- **표시 언어**: 오른쪽 위 「한·日 ▼」 버튼(줄바꿈 없이 고정 폭) → 한국어·日本語(기본) / 한국어·English / 日本語·English 중 두 언어, 일본어 발음 보기 켬/끔. 기기별로 기억.
- **도우미**: 오른쪽 위 도트 반짝이 아이콘(글자 없이, 이모지 대신 도트 — 2026-10-23 사용자 「AI 스러운 아이콘」 요청). 아래에서 올라오는 시트, 「상대에게는 보이지 않아요」. 지금까지의 대화를 맥락으로 답하고, 끝의 「말해 볼 문장: 일본어 (발음)」은 카드로 떼어 「대화에 넣고 보여주기」(내 말풍선으로 넣고 바로 크게 보여주기).
- **입력**: [⌨ 글로 쓰기] [한국어] [日本語]. 말하기 버튼 둘은 같은 너비·모양·글꼴, **색은 언제나 다르게**(2026-10-23 사용자): 한국어 = 주홍(내 말풍선 쪽), 일본어 = 먹(상대 말풍선). 평소엔 그 색으로 채움, 녹음 중엔 뒤집어 종이 바탕 + 그 색 굵은 테두리·글자 + ● 깜빡임(「듣는 중」/「聞いています」) + 그 색 소리 막대, 위에 같은 색 상태 줄(「한국어 듣는 중 · 다 말하면 저절로 끝나요 · 누르면 바로 끝」), 받아 적는 중 점선 말풍선도 같은 색. 다른 쪽 버튼은 흐리게. (이전 #55: 평소엔 둘 다 종이색에 마이크만 색 → 「색을 다르게 유지」 피드백. 그 전: 넓은 주홍 + 좁은 먹 버튼, 일본어 녹음 색이 평소 한국어 버튼과 같아 헷갈림) 말하기는 누르면 녹음, 말이 끝나고 1.3초 조용하면 저절로 끝(다시 눌러도 끝, 8초간 말이 없으면 끝, 최대 30초). 녹음 중 버튼 아래 소리 크기 막대. 글로 쓰기는 OS 키보드라 일본어 키보드를 추가하면 일본어도 쓸 수 있고, 서버가 언어를 판별한다(일본어로 쓰면 상대 말풍선으로).
- **빨리 보여주기**: 받아 적는 동안 점선 말풍선 「받아 적는 중」, 받아 적으면 말풍선을 먼저 띄우고 번역문 → 발음·영어 순으로 채운다(서버가 JSON 필드를 닫히는 대로 보냄).
- **음성 인식 오류 바로잡기는 「소리가 거의 같은 말」까지만**(2026-10-23): 한국인이 일본어를 말하면 Whisper 가 말머리를 「はい」로 끊는다(하이자라 → 「はい、ざら」). 번역 단계가 단어 경계·한자·장음·탁음만 바꿔 맞는 말이 되면 고치고(→ 灰皿), 소리가 다른 말·대화에 없는 내용으로는 바꾸지 않는다. 이전 프롬프트(「문맥상 가장 그럴듯한 말」)는 「とりあえず生」·「麦茶」·「アイスジャスミン茶」처럼 아무도 하지 않은 말을 지어냈다. 바로잡은 원문은 말풍선 작은 줄에 보인다.
- **「日本語」 버튼은 원어민(점원)용**(2026-10-23 확인): 한국인이 일본어를 직접 말하면 억양 때문에 무료 음성 인식이 「はい、じゃあ…」처럼 멀쩡한 다른 문장으로 받아 적어 바로잡을 수 없다. 사용자는 「한국어」로 말하고 크게 보여주는 기본 흐름을 쓴다. 개선 후보는 [[backlog]].
- **무음 녹음은 보내지 않는다**: Whisper 는 무음에도 「감사합니다」를 지어낸다([[benchmarks]]). 말소리(RMS 0.02 이상)가 0.3초 미만이면 「말소리가 들리지 않았어요」.
- **음성 인식을 못 쓸 때**: 한도 때문이고 다시 될 시간을 알면 「음성 인식 한도에 걸렸어요 · N분 뒤 다시 돼요 · 글로 쓰기는 지금도 돼요」, 모르면 「지금은 음성 인식을 쓸 수 없어요 · 관리자에게 문의해 주세요 · 글로 쓰기는 돼요」(2026-10-23 사용자 결정). 어느 쪽이든 입력을 글로 쓰기로 바꾼다.
- **제목**: 완료 2마디에 「이모지 + 14자 이내」 자동 제목, 6마디에 한 번 더(고친 이름이 있으면 짓지 않음). 헤더 제목을 누르면 이름 고치기(스캔 기록과 같은 모달).

## 기록

- 대화는 마디가 끝날 때마다 저장(번역 중에 화면을 떠나면 받은 데까지 저장, 번역문이 없던 마디는 「다시 번역」). 기기에만 저장(IndexedDB `menulens-talk`, 스캔 기록 DB 와 분리해 기존 형식·버전을 건드리지 않음).
- 목록 줄은 스캔 기록 줄과 같은 모양: 말풍선 도트 글리프 + 제목 + 「대화 · 시각」 + 연필·휴지통. 정렬·날짜 머리말은 마지막으로 이어 말한 시각. 지우기는 확인 팝업. 대화 「전체 지우기」는 두지 않았다.

## 서비스 선택 (2026-10-23 사용자 결정)

- 음성 인식: Groq Whisper(무료 등급) → 예비 Gemini 받아쓰기 모델(무료 등급, 입력이 Google 제품 개선에 쓰일 수 있음을 알고 채택). 브라우저 내장 음성 인식은 품질 우려로 쓰지 않음. 번역·도우미: Timely, 한도 문제일 때만 Anthropic 직접 키(Max 크레딧). ChatGPT Pro·Google Workspace 구독에는 API 크레딧이 없다(공식 문서 확인).
