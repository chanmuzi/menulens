# 남은 과제

## 사용자 결정 대기

- (없음) 2026-10-20 결정: 홈 기본 버튼은 「촬영」 유지. `DEBUG_STORE` 는 재현할 케이스가 없을 때 끈다(현재 0). "121단어" 케이스는 식별 불가로 종료.

## 기능

- 촬영 사진 크롭·90° 회전 편집(캔버스 기반). 반나절 규모.
- 사진 모드 재개: 자주 나오는 메뉴 300~500개의 사진·설명 사전 구축(라이선스 허용 소스), 없는 것만 검색 → 캐시.
- 초대 코드별 일일 호출 한도(Redis 카운터로 가능해짐).
- PWA manifest·홈 화면 아이콘.
- 최근 스캔 보관 수(현재 5건) 조정, 전체 삭제 버튼 — 사용자가 원하면.
- 도트 아이콘 부족 재료는 실제 메뉴판 사례를 보며 수작업 추가(LLM 즉석 생성은 화풍 불일치 위험으로 보류).

## 품질·속도

- 2단계 설명 묶음 간 지연 편차(5~15s). 캐시 누적으로 완화 예정.
- 원근 왜곡 보정(현재 회전·기울기만).
- Safari 실기기 회귀 확인 체크리스트: 결과 기본 탭, 처리 중 중앙 정렬, 핀치·스크롤, 공유 시트 저장, 자동 새로고침.
