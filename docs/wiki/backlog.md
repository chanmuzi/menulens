# 남은 과제

## 사용자 결정 대기

- (없음) 2026-10-20 결정: 홈 기본 버튼은 「촬영」 유지. `DEBUG_STORE` 는 혼자 테스트하는 동안 켜 두고(현재 1), 코드를 나눠주기 시작하면 끈다([[debug-store]]). "121단어" 케이스는 식별 불가로 종료.

## 기능

- 확인 화면에서 90° 회전 편집(크롭은 2026-10-20 반영).
- 사진 모드 재개: 자주 나오는 메뉴 300~500개의 사진·설명 사전 구축(라이선스 허용 소스), 없는 것만 검색 → 캐시.
- 초대 코드별 일일 호출 한도(Redis 카운터로 가능해짐).
- 생성 아이콘 중 자주 나오는 것을 정식 스프라이트로 승격(`pixel-icon` 스킬).
- 안내문·표지판(sign) 전용 결과 UI. 이슈 #6.

## 품질·속도

- 2단계 설명 묶음 간 지연 편차(5~15s). 캐시 누적으로 완화 예정.
- 원근 왜곡 보정(현재 회전·기울기만).
- Safari 실기기 회귀 확인 체크리스트: 결과 기본 탭, 처리 중 중앙 정렬, 핀치·스크롤, 공유 시트 저장, 자동 새로고침.
