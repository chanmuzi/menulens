## 기능

- `App.tsx` 의 스캔 오케스트레이션(`runScan`·`startScans`·`prewarm`·`addScans`·`retryOne`·`batch`·`files`·`ctrls`·`draft`, 이름 고치기 `rename`)을 `useScans` 훅으로 분리(동작 변경 없는 리팩터, 2026-10-21 리뷰 제안). 숨은 파일 입력(홈·모음 화면·띠 세 곳)도 `usePhotoInput` 훅으로 묶을 것. 묶음 띠 ARIA 는 `aria-current` 로 두었고 탭 패턴(tabpanel·화살표 이동)은 미구현.
- 자르기 화면(`CropScreen`)에서 90° 회전 편집(확인 화면은 모음 화면으로 흡수, 2026-10-22).
- 사진 모드 재개: 자주 나오는 메뉴 300~500개의 사진·설명 사전 구축(라이선스 허용 소스), 없는 것만 검색 → 캐시.
- 초대 코드별 일일 호출 한도(Redis 카운터로 가능해짐).
- 생성 아이콘 중 자주 나오는 것을 정식 스프라이트로 승격(`pixel-icon` 스킬).
- 안내문 덮개 잔여(이슈 #6 은 종결, 2026-10-23 문단 덮개·요약/번역문/원문 탭 반영 [[overlay-and-photo]]). 남은 것: 같은 이름표 묶음의 글자 크기 통일, 문단이 OCR 묶음(60단어) 경계에 걸리면 둘로 나뉨. 처리 중 화면의 안내문 문구가 아직 「줄마다 번역하는 중 / N줄 번역했어요」(문단 단위와 안 맞음, `ProcessingScreen.tsx` `translateStep`).

## 역방향(한→일) 남은 것 (2026-11-01, PR #63~#69 뒤)

- 발음 규칙 보강: 한글 → 가타카나의 ㅎ 격음화(축하해요 → チュカヘヨ, 어떻게 → オットッケ), 같은 항목 11개 이상의 수 읽기(「11ケ」·「11코」), 가나 → 한글에서 ん 의 ㅇ 받침(か행 앞). 규칙은 `scripts/bench/rules_test.ts`·`talk_test.ts` 에 케이스를 먼저 넣고 고친다.
- 옛 기록: 역방향 전 일→한 기록의 발음은 모델이 지은 값이 그대로 남아 있다(다시 분석·다시 번역하면 규칙 발음). 일괄 재생성은 하지 않기로(비용·사용자 결정 없음).
- 주문서: 한 묶음에 원문 언어가 다른 메뉴판이 섞이면 첫 메뉴판 언어의 사진만 담긴다(다른 사진에는 담기 버튼이 없다). 안내 문구 없음 → 실제로 겪는 사람이 생기면 안내 추가.
- 챗·통역의 언어 기준은 사진·대화를 만들 때의 앱 언어다. 스캔 뒤 앱 언어를 바꾸면 답은 옛 언어, UI 는 새 언어([[design-decisions]]). 바꾸려면 다시 분석.
- 실기기 미검증(일본어 모드): 일본어 글꼴(IBM Plex Sans JP) 표시, 대화 통역 마이크(「日本語」 버튼이 내 쪽), 공유 시트·클립보드. 실제 한국 식당 메뉴판 사진은 합성·Commons 사진으로만 검증했다([[benchmarks]]).
- 안내문·기타 종류의 일본어 모드 팁·문구는 한국 여행 기준으로 썼으나 실제 일본인 사용자 피드백은 없다.

## 품질·속도

- `src/lib/api.ts` 의 분석 스트림 읽기도 `ndjson.ts` 공용 함수로(chat·talkApi 는 2026-10-23 옮김, 핵심 경로라 따로 확인 후).
- 대화 통역 억양 일본어(2026-10-23, 사용자 결정 대기): 한국인이 「日本語」 버튼으로 일본어를 말하면 「はい、じゃあ…」로 인식된다([[benchmarks]]). 후보 ① 인식된 원문을 눌러 고친 뒤 다시 번역 ② 발음 표기에서 한국어에 없는 소리(ざ·ず·ぜ·ぞ 등)를 「자(z)」식으로 구분해 점원에게 읽어 줄 때 같은 문제를 줄이기 ③ 진단 모드에서만 최근 녹음 몇 건을 Redis 에 저장해 실제 목소리로 원인 확인(사용자 음성이 서버에 남으므로 결정 필요, 절대 규칙 4).
- 대화 통역 실기기 확인(미검증): iPhone 홈 화면 앱에서 마이크 권한·녹음(audio/mp4)·말이 끝나면 저절로 끝나는지·가게 소음에서 무음 거르기 기준(RMS 0.02)·크게 보여주기 글자 크기. Gemini 예비 받아쓰기는 2026-10-23 내내 503 이라 품질 미측정 → 실제로 넘어간 적이 있는지 Vercel 로그 `[stt]` 로 보고, 계속 503 이면 예비 경로를 바꿀지 사용자 결정. [[decisions-talk]]

- 2단계 설명 묶음 간 지연 편차(5~15s). 캐시 누적으로 완화 예정.
- 원근 왜곡 보정(현재 회전·기울기만).
- Safari 실기기 회귀 확인 체크리스트: 결과 기본 탭(오버레이), 처리 중 중앙 정렬, 핀치·스크롤, 공유 시트 저장, 자동 새로고침, 홈 앱 상단 띠, 중단 확인, 챗 시트·키보드, 기록 썸네일·이름 고치기 모달·지우기 확인, 작은 연필·휴지통 누르기.
