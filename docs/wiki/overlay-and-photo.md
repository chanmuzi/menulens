# 화면 좌표·회전·라벨 규칙

## 좌표

- 모든 좌표는 **원본 사진을 0~1000 으로 정규화**한 값. 항목 bbox = 그 항목 `word_ids` 의 OCR 단어 상자 **합집합**(`src/lib/scan.ts unionBox`). 이미지 폴백 모드에서만 모델이 준 bbox 를 쓴다(정확도 낮음).
- 역사: 처음엔 Claude 가 이미지에서 bbox 를 직접 추정했는데 반 칸~수십 px 씩 어긋났다(모델 한계) → OCR 단어 상자로 전환해 해결.

## 사진 세우기 (`src/components/MenuPhoto.tsx`)

1. EXIF 방향: `<img>` → canvas 경로가 모든 최신 브라우저에서 적용(createImageBitmap 의 imageOrientation 은 Safari 신뢰 불가).
2. 글자 방향 `rotation`(0/90/180/270): OCR 단어 vertices[0]→[1] 방향의 중앙값을 90° 로 반올림(`api/_lib/ocr.ts`). 세로쓰기 일본어는 글자가 서 있어 0°.
3. 미세 기울기 `tilt`: 위 중앙값에서 90° 배수를 뺀 나머지. ±15° 이내만 되돌린다.
4. 글자 영역 확대: 단어 상자 합집합 + 8% 여백(`focusBox`)이 상자에 꽉 차도록 CSS transform 하나로 회전·확대·중앙 정렬. 원근 왜곡은 펴지 않는다.
5. 마커는 사진과 같은 레이어에 % 로 두고, `markerScale = 1/(fit.scale × zoom)` 을 곱해 화면 크기를 일정하게 유지한다.

## 마커 선택 규칙 (`src/screens/OverlayView.tsx`)

| 대상 | 표현 |
|---|---|
| 메뉴 항목 ≤4개이고 사진 회전 없음 | 이름·가격 칩. 세로쓰기면 3단으로 엇갈려 배치 (`CHIP_LIMIT=4`, `OverlayView.tsx`) |
| 그 밖(기본) | 번호 배지 20px, 붐빌 때만 13px 까지(이웃 항목과의 화면 거리 ×0.85) + 사진 아래 번호 목록 |
| 안내문·기타의 문단(notes) | **문단 덮개**(아래 「안내문 덮개」). 들어가지 않으면 줄 왼쪽에 번호 배지 + 사진 아래 번역문에 같은 번호 |
| 메뉴판의 notes(제목·안내 문구) | 사진 위에 그리지 않는다 |

## 터치

- 페이지 줌은 끔(`user-scalable=no`) → 상세 시트가 확대된 채 뜨지 않는다.
- 확대 전 `touch-action: pan-y`: 한 손가락은 페이지 스크롤, 두 손가락만 사진 확대(최대 4×). 확대 중 `none`: 한 손가락이 사진을 끈다. 두 번 탭 또는 「원래대로」 버튼으로 복귀.
- React 의 touch 리스너는 passive 라 `preventDefault` 가 듣지 않는다 — 제어는 전부 `touch-action` 으로.
- 「표시 끄기」 토글(결과 화면 제목 줄 오른쪽, `ResultScreen` 이 상태를 들고 `showMarks` 로 내려줌)로 모든 마커를 숨긴다. 사진 아래 조작 안내 문구는 없다(2026-10-21 삭제).

## 실기기 확인이 남은 것

핀치·끌기·공유 시트는 헤드리스로 재현 불가. 변경 후에는 사용자 확인을 요청한다.

## 안내문 덮개 (2026-10-23 문단 덮개)

이전 방식(줄마다 번역한 반투명 상자, 2026-10-20~22)은 조각 번역·떨어진 줄 합침·글자 넘침으로 겹치고 안 읽혔다 → 진단 기록 실사진으로 비교 후 교체([[log/2026-10]]).

- **문단 단위**: 1단계가 sign·other 이면 notes 를 `{role, lines:[[단어 id…]…], text, tr}` 문단으로 낸다. 문장이 여러 줄이면 한 문단으로 묶어 문장 단위 번역. `toNote` 가 줄 상자 `lines` 와 합집합 `bbox` 를 만든다. 이전 기록·메뉴판·이미지 폴백은 `lines` 없이 `bbox` 하나 → 그 상자를 한 줄로 본다.
- **그리기**(`src/components/NoticeCovers.tsx`): 원문은 줄 상자마다 사진 배경색(불투명)으로 지우고, 번역은 글자 영역에 줄바꿈해 쓴다. 바탕을 모두 깐 뒤 글자를 올린다. 글자색 대비가 4.5:1 미만이면 먹색/종이색(`sample.ts`).
- **덮개 / 번호 판정**(`src/lib/coverLayout.ts`, 사용자 결정 2026-10-23):
  1. 글자 영역 = 문단 줄 상자 합집합에서 다른 문단의 줄과 겹치는 쪽을 잘라낸 사각형.
  2. 글자 크기 상한 = 원문 줄 굵기 ×0.8 (제목 26px·나머지 20px 까지, 화면 기준).
  3. 화면 기준 **11px** 이상으로 안 들어가면 이웃 줄·앞 문단 글자 영역에 닿지 않는 범위로 가로 +80%·세로 +60% 까지 넓혀 다시 넣는다.
  4. 그래도 안 들어가면 **번호 배지**(줄 왼쪽 바깥, 이웃 거리로 14~20px). 번호는 확대 전(1×) 배치로 정해 목록 번호가 바뀌지 않는다.
  5. 두 손가락으로 확대하면 그 배율(0.5 단위)로 다시 배치해, 번호였던 문단도 들어가는 만큼 제자리 덮개로 바뀐다(출구 안내판: 1× 덮개 2·번호 32 → 3× 덮개 32·번호 2).
- **선택**: 덮개·배지·번역문 줄은 선택 하나를 공유한다. 누르면 사진에 빨간 테두리 + 번역문 탭에서 그 줄 강조(목록 안에서만 스크롤), 같은 것을 다시 누르면 해제. 원문·번역 시트(`NoteSheet`)는 정리 영역과 중복이라 삭제.
- **사진 아래 정리 영역**(`src/screens/NoticePanel.tsx`): 요약 / 번역문 / 원문(복사) 탭. 요약은 1단계 뒤 별도 호출(`SUMMARY_SYSTEM`)로 사진에 적힌 내용만, 사진에 없는 일반 상식은 `tips` 로 따로 받아 점선 「참고 · 사진에 없는 일반 정보」 상자에 둔다. 엔화 옆 원화는 모델이 아니라 앱 환율로(`splitYen`). 요약 없는 이전 기록은 요약 탭을 숨긴다.
- 사진 층이 `rotation + tilt` 만큼 돌아가 있으므로 글자는 역회전한다. 90·270 이면 x·y 를 바꾼 좌표에서 배치하고 되돌린다. 한글은 세로쓰기 원문이어도 가로로 쓴다.
- 일본어 문단만 번역하고 영어·한국어·중국어 병기 줄은 건드리지 않는다.
